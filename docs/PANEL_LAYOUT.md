# Настройка размеров панелей

Изменения основаны на загруженной ветке `feature/layout-emoji-gif`. Готовая реализация эмодзи и GIF сохранена; повторная библиотека или новый GIF-провайдер не добавлялись.

- В ленте изменяется ширина правой колонки, включая панель виджетов.
- В личных чатах отдельно изменяются список переписок и панель информации справа.
- В групповых чатах изменяется список групп.
- Потяните вертикальный разделитель мышью. С клавиатуры: Tab до разделителя, ←/→ для изменения, Shift для крупного шага, Home/End для границ. Двойной щелчок или Enter возвращает исходную ширину. Escape отменяет текущий жест.
- Предпочтения сохраняются на этом устройстве отдельно для каждого аккаунта. При уменьшении окна отображаемая ширина временно ограничивается; сохраненное предпочтение не перезаписывается.
- Основная переписка остается шириной не менее 360 px на desktop. Если колонки не помещаются, информация открывается отдельной панелью; на телефоне сохраняется последовательный интерфейс «список → чат».

Дополнительно выровнены заголовки и кнопки, у поля ввода появилась адаптивная высота и отдельный ряд действий при узкой переписке. Навигация прокручивается независимо от закрепленной кнопки «Создать», с минимальным отступом 18 px. Пустое состояние групп оформлено карточкой; списки и история сообщений имеют отдельные области прокрутки.

Новых зависимостей, миграций базы или production-настроек для размеров панелей нет. Регрессии проверяют поврежденные сохраненные значения, ограничение ширины, клавиатуру, pointer capture, отмену и изоляцию указателей. Существующий тест групп также проверяет изменение и account-scoped сохранение ширины, сохраняя проверки истории, пагинации и устаревших ответов.
