# Персональная панель виджетов

Панель находится справа от главной ленты вместо рекомендаций. В других разделах рекомендации сохранены. На экранах до 1050 px панель открывается кнопкой «Мои виджеты»; это тот же экземпляр состояния, а не отдельная мобильная копия.

## Первый набор

| Виджет | Возможности |
|---|---|
| Календарь | Выбор даты, собственные события и их удаление |
| Задачи | Добавление, отметка выполнения и удаление |
| Заметки | Редактирование личной заметки |
| Фокус | Таймер с запуском, паузой и сбросом; расчет по времени окончания |
| Обратный отсчет | Название события и дата/время |
| Валюты | EUR, USD, PLN, GBP, CHF; справочные курсы Frankfurter с датой источника |
| Ссылки | Собственный список ссылок с безопасными HTTP/HTTPS адресами |
| Цель | Название, целевой показатель и прогресс |

Каталог позволяет найти и добавить виджет, убрать его из панели, свернуть и поменять порядок кнопками. Наборы для учебы, исследований и работы добавляют недостающие виджеты, сохраняя текущие записи. Удаление виджета удаляет и его локальное содержимое; это явно обозначено в интерфейсе.

Пользователь выбрал **пока только локальный календарь**. Google Calendar не подключен; OAuth-запросов и доступа к аккаунту Google в этой версии нет. План отдельного подключения описан в [GOOGLE_CALENDAR_SETUP.md](GOOGLE_CALENDAR_SETUP.md).

## Данные и границы

- Панель и пользовательские записи сохраняются на этом устройстве в account-scoped localStorage. Между устройствами данные не синхронизируются. Смена аккаунта использует существующую SessionBoundary; экспорт/очистка локальных данных включают виджеты.
- Проверка структуры, длин строк, количества записей, дат и ссылок выполняется перед отображением сохраненного состояния. HTML из заметок не исполняется.
- Курсы загружаются через публичный `/api/widgets/rates`, обращающийся к фиксированному Frankfurter API. Выбор базовой валюты ограничен. Нет пользовательского URL, API-ключа или доступа к личным данным.
- Источник публикует справочные курсы по рабочим дням, а не биржевые котировки в реальном времени. Интерфейс показывает дату. При сбое отображается ошибка с повтором запроса, без выдуманных значений.
- Миграции Supabase, изменения production и новые зависимости для этой функции не нужны.

## Расширение каталога

Следующие независимые срезы: Google Calendar с отдельным согласием, часовые пояса, расписание занятий, учебные дедлайны, привычки, исследовательские ссылки/библиография, научные события, командные задачи и финансовые наблюдения. Каждый внешний источник должен иметь явные разрешения, квоты, дату обновления и состояния загрузки/ошибки. Персональные данные сторонних аккаунтов не должны храниться в localStorage.

Готовые наборы — стартовая конфигурация, а не ограничение по профессии. Новый виджет добавляется через тип и валидатор модели, карточку в каталоге, рендерер и проверки его границ. Результаты конкретного запуска проверок записываются в описание PR.

## Проверки первого варианта

Полный `npm run verify` прошел: 51 тест, TypeScript, ESLint без ошибок (39 прежних предупреждений по изображениям), SQL/RLS, сканер секретов, аудит зависимостей и сборка. В браузере проверены desktop и ширина 390 px: редактирование и сохранение записей, перестановка, добавление набора без потери данных, фокус каталога, вложенный Escape и возврат фокуса/прокрутки после закрытия мобильной панели. Реальный HTTP-запрос курсов вернул 200, неподдерживаемая валюта — 400. Проверки пяти базовых валют у источника прошли. Это проверка виджетов; она не заменяет оставшиеся проверки почтовых/Auth-сценариев всего приложения.
