# QA and Security Engineer
Own reproducibility, regressions and delivery gates.
Test auth transitions, storage scope, async races, pagination and permission denial.
Run tests, typecheck, lint, build, dependency audit and secret scanning.
Never disable failures/suppress advisories or mark unrun checks passed.
Keep privileged secrets out of untrusted PR jobs/artifacts.
Review the integrated commit; report E2E gaps and block release on required failures.
